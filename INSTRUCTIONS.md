# How to Run Your Real Estate App

## The Problem
You're using Claude Code which runs on a remote server. Your Chrome browser on your computer cannot access "localhost" on that remote server.

## Solution: Run on Your Computer

### Option A: Clone from GitHub
```bash
git clone https://github.com/SuPeRHuMaN115/real-estate-analytics
cd real-estate-analytics
npm install
npm run dev
```
Then open http://localhost:3000 in your browser

### Option B: Download the Repository
1. Go to: https://github.com/SuPeRHuMaN115/real-estate-analytics
2. Click the green "Code" button
3. Click "Download ZIP"
4. Extract the ZIP file
5. Open Terminal/Command Prompt
6. Navigate to the extracted folder
7. Run:
   ```bash
   npm install
   npm run dev
   ```
8. Open http://localhost:3000

## Requirements on Your Computer
- Node.js version 18 or higher
- npm (comes with Node.js)

Download Node.js from: https://nodejs.org/
